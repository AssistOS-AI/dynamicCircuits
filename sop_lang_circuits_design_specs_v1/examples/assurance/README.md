# Assurance templates comune

Acest folder ilustrează două hooks obligatorii:

1. contradiction: leagă support pozitiv și negativ pentru aceeași propoziție;
2. grounding: leagă un output textual de conflictele relevante.

Exemplele sunt intenționat simple. În producție, grounding-ul trebuie să folosească claim extraction și semantic coverage, nu simpla căutare a unor cuvinte.
