# Template Review Checklist

- [ ] Semantica regulii este scrisă.
- [ ] Inputs/outputs au ordine stabilă.
- [ ] Applicability este separată.
- [ ] Matcher produce handles, nu values inventate.
- [ ] Mandatory matcher este exhaustiv.
- [ ] Trigger-ele au recall suficient.
- [ ] Rule produce witness.
- [ ] Verifier este independent sau certificate-based.
- [ ] Tests pozitive/negative/boundary există.
- [ ] Contextul este explicit.
- [ ] Limitările sunt documentate.
- [ ] Package hash este fixat pentru profile.
