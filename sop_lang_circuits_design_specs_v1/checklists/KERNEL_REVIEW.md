# Kernel Review Checklist

- [ ] Calls sunt poziționale.
- [ ] Literalii sunt ghilimați.
- [ ] Missing command args devin undefined.
- [ ] Circuit arity este strictă.
- [ ] No implicit capture.
- [ ] Wires sunt locale și SSA.
- [ ] JS este sandboxed.
- [ ] Refusal diferă de error.
- [ ] Receipts sunt canonice.
- [ ] Mandatory matchers sunt restricted.
- [ ] Closure are final audit.
- [ ] Goals/invariants au coverage.
- [ ] Profile-ul este extern attempt-ului.
- [ ] Cache nu promovează trust.
