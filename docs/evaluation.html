Deterministic tests and agent evaluations

Unit suites establish language and orchestration mechanics. Three browsable evaluation workspaces test legal exception handling, scientific counterexamples, and cross-document conflicts using executable circuits and committed evidence.

Unit test organization

SuiteContract under test

tests/runtime/Command ABI, checks, refusal, errors, nested execution, and assurance outcomes.

tests/agents/Codex arguments and generic adapter extensibility.
tests/cli/The public single-dash invocation form and dry-run behavior.
tests/integrity/The immutable historical v1 package aggregate hash.
tests/docs/Relative specification links remain valid below a static mount prefix.

DS001 is authoritative for test organization. Run npm test for code and npm run check for code plus documentation verification.

Historical integrity

The original design package remains an immutable baseline. Initialization and later migrations must compare its aggregate file hash before and after work. Current requirements live in the contiguous DS set and must be regenerated into the specification matrix.
