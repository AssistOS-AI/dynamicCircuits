# Identity incident handoff

Document title: Identity Gateway SEV-1 Handoff

Service: Identity Gateway

Severity: SEV-1

Incident commander role: Security Incident Commander

Outgoing role: Authentication Primary

Incoming role: Authentication Relief

Acknowledgement deadline: 1 minute

Escalation deadline: 2 minutes

Evidence locations: authentication error graph; token validation trace; customer-impact log; change audit

Communication channel: #inc-identity

Prohibited action: rotate signing keys during handoff

Approval role: Security Incident Commander

Generate and independently verify the SOP. Do not perform operational actions.
