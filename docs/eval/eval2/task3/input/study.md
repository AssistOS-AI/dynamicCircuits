# Boundary-counterexample study

Evaluate the claim that every observation is strictly positive. Compute the mean separately and select the first value that
refutes the claim in source order.

| Observation | Z1 | Z2 | Z3 | Z4 |
|---|---:|---:|---:|---:|
| Value | 0 | 5 | -1 | 10 |

Zero is not strictly positive. These four finite values are the complete dataset.
