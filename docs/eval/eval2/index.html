Eval 2: universal claim and counterexample

This case checks whether executable analysis separates an aggregate statistic from a universal claim and returns a source witness when one observation refutes that claim.

How the evaluation works

claim.md, rule.md, dataset.md, and task.md are the documents available to the coding agent. The generated dataset.sop is the explicit executable interpretation of the Markdown table. counterexample.sop is a reusable circuit that accepts an observation array, validates it, calculates the mean, and finds the first non-positive witness. analysis.sop composes both packages and grounds the witness.

The runtime executes the root circuit with no JSON source input. It succeeds technically while returning semantic verdict REFUTED. This distinction is the main evaluation target: a successful analysis can correctly produce a negative domain conclusion.
