Eval 10: Multi-round mandatory closure

Raw-order publications activate normalization; each normalized order publishes a new fact that activates two independent second-round assessments.

What this evaluation proves

This case tests a real fixed point rather than a flat list of calls. The task circuit knows only the current raw orders and publishes them as order.raw. The reviewed normalization matcher discovers those facts. Its target emits normalized values and order.normalized publications, which activate approval and currency matchers in the next productive round.

For N valid orders the complete set contains N normalization instances plus 2N assessments. The three tasks therefore expect six, three, and six executed instances. Unsupported currency and missing approval are ordinary non-compliant findings; closure still succeeds when every applicable circuit executes and all expected instance identities appear in the audit.

Use the tree to compare human rules with reviewed matchers, generated task SOP, and executor output. The complete mechanism and its present exact-key limitation are described in Mandatory rules and closure; DS016 defines the fixed-point contract.
