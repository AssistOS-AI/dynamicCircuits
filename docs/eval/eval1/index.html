Eval 1: notice-period exception

This case checks whether a coding-agent interpretation preserves an ordinary 30-day rule, applies a 10-day exception only when both expedited treatment and written consent are present, and classifies every supplied case.

How the evaluation works

The source side consists entirely of prose and a Markdown table. rule.md states the policy, cases.md states the facts, and task.md states the requested outputs. The generated policy.sop turns the reusable rule into executable code with explicit case inputs. The task-specific analysis.sop encodes the three interpreted cases as calls to that rule, aggregates findings, and verifies complete classification.

The runtime executes eval1.analysis with no JSON input. Its public findings and statistics are compared with results/result.json. The successful runtime outcome confirms that the executable interpretation produced the committed result; the scope limit remains the authority and completeness of the supplied policy text.
