Evaluation catalog

Each evaluation folder has one self-contained page. Its left menu groups source documents, generated SOP code, and observed results; selecting a file shows its purpose, relationship to the evaluation, and exact content on the right.

Purpose of the catalog

The catalog separates evaluation cases so the interface remains usable as the repository grows. An evaluation page explains one question and one artifact set. It does not mix filenames or explanations from unrelated cases. The source material under input/ is human-readable Markdown intended for a coding agent. The SOP folder contains the executable interpretation authored from that material. JSON is used only for machine-readable results, not as source input to the coding agent or as a hidden parsing layer inside the circuits.
