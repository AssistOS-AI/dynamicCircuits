What is actually tested

tests/runtime/eval.test.mjs reads the committed source data and text, executes all three circuit graphs, and checks exact public outputs and assurance goals. Other suites independently test parser/compiler failure paths, workspace mode inference and links, coding-agent invocation, CLI migration behavior, static documentation links, and historical integrity.

These are deterministic circuit evaluations, not recorded claims about a particular model's quality. A future coding-agent benchmark can run the same workspaces from raw prose and compare its authored circuits and reports against these committed contracts.
