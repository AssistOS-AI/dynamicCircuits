What these evaluations measure

The three cases test the deterministic SOP implementation against committed reference tasks. Each unit test reads the committed inputs, executes the committed circuit packages, and compares their public outputs with results/result.json. The cases cover exception handling, exhaustive counterexample search, repeated child circuits, cross-document aggregation, source attribution, and goals.

These fixtures evaluate circuit and runtime behavior. They do not currently measure how reliably a particular version of Codex authors the same circuits from raw documents. A future coding-agent benchmark can use these inputs and expected results as its reference dataset.
