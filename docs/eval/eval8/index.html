Eval 8: Contractual notice generation

One reviewed legal-style generator–verifier family produces three fact-bounded notices and checks omissions, exhibit order, supplied terms, and unsupported additions.

What this page lets you inspect

Tasks 1 and 2 cover distinct agreements and factual events. Task 3 tests a subtle boundary: a currency symbol and disputed phrase are permitted only because the brief supplies them. All three executor reports pass independent verification without adding other legal conclusions.

The shared tree starts with an evaluation-record branch, one Knowledge base branch, and three independent Task branches. Inside the KB, source documents and reviewed circuits have separate child branches. Inside each task, input, generated SOP, executor output, and evaluation evidence also have separate child branches. The hierarchy makes file authority visible before a file is opened.

Expectation files are outside every input/ directory and are consulted only after execution. The navigation structure and file explanations come from one shared manifest, eval-manifests.js, rather than copied page-specific menus. Read the evaluation method and DS007 for the common contract.
