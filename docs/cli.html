Documentation / CLI and workspaces

One KB, one current task

The CLI keeps reusable knowledge separate from the current analysis. It prepares the directory contract before any coding-agent process starts.

Prepare and analyze

agent prepare -kbdir ./kb -workdir /path/to/task
agent -kbdir ./kb -workdir /path/to/task -agent codex
agent run --kbdir ./kb --workdir /path/to/task --agent codex --learn

Both single-dash and conventional double-dash forms are accepted for KB, workdir, and agent options. Preparation creates missing directories, inventories inputs, and links the project skill catalog at circuitSkills and .agents/skills. It refuses overlapping KB/work roots and conflicting skill-link paths.

Agent authority

Normal analysis treats the KB as read-only. Learning mode lets the Codex sandbox write under the KB root, while the generated instructions restrict reusable output to candidates/. This restriction is currently instructional rather than a host-mediated filesystem capability; DS008 records the limitation.

--prepare-only stops before adapter construction. --dry-run prints the command, arguments, working directory, and prompt without launching a process. The generic adapter accepts a program through --agent-command and sends the prompt through standard input. Installed compatibility aliases are dc-agent and dynamic-circuits.

Workspace skill catalog

analyze-task enforces complete input coverage and grounded results. author-sop-circuit supplies the implemented syntax and verification loop. circuit-learner separates reusable candidates from task-specific facts. The CLI links the catalog as one directory so the same instructions govern normal tasks and evaluation cases.
