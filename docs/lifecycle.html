The complete analysis lifecycle

The design follows evidence from immutable source bytes through interpretation, reusable knowledge, execution, assurance, repair, and qualified publication.

Phases A–I

flowchart LR
  A[A Ingest] --> B[B Interpret]
  B --> C[C Discover]
  C --> D[D Wire]
  D --> E[E Execute]
  E --> F[F Close]
  F --> G[G Assure]
  G -->|failure evidence| H[H Repair new attempt]
  H --> D
  G -->|accepted| I[I Publish receipt and report]

Ingest captures immutable artifacts, digests, locators, access policy, and epoch. Interpretation publishes facts with provenance and uncertainty. Discovery proposes templates and deterministic matchers verify applicability. Wiring creates explicit instances; execution schedules only the relevant dependency slice; closure exhausts mandatory obligations; assurance applies goals, trust, conflicts, budgets, and profile gates. Repair creates an immutable child attempt. Publication never labels a partial or failed result as accepted.

DS027 includes legal exception, scientific counterexample, and cross-document conflict reference flows. Their current executable forms are browsable in the evaluation catalog.

Roadmap and design choices

The staged roadmap moves from syntax and deterministic IR through runtime, workspace orchestration, persistent evidence, semantic templates, mandatory closure, hardened capabilities, and distributed scale. Implemented subsets never imply the next stage. Module and schema compatibility rules are in DS024.

The architecture deliberately combines compiler/dataflow SSA, rule-system fixed points, workflow-style effects and attempts, and proof/evidence-style receipts. Datalog, CHR, attribute grammars, semantic parsing, rewriting systems, proof assistants, proof-carrying computation, e-graphs, dataflow engines, and workflow systems each inform a layer but do not cover the entire problem alone. The comparative rationale and rejected surface choices are preserved in DS025.

What exists now

The current repository delivers parser, package discovery, graph compiler, deterministic runtime, local checks/invariants, receipts, inferred CLI modes, skill-linked agent workspaces, three serious evals, and documentation/integrity tests. Attempts, semantic indexing, automatic wiring, closure, profiles, trust registry, persistent cache, artifact store, production isolation, certificates, and distributed execution remain planned.
