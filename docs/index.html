Documentation / Overview

Executable analysis workspaces for coding agents

Dynamic Circuits prepares a task directory, exposes reusable SOP Lang circuits from a separate knowledge base, and asks an external coding agent to create and execute the analysis. The reference kernel keeps circuit mechanics inspectable and independent from direct LLM APIs.

Implemented system

flowchart LR
      U[CLI invocation] --> W[Workspace preparation]
      W --> M[Input manifest]
      W --> S[Circuit skills link]
      K[KB circuits] --> A[Coding-agent process]
      M --> A
      S --> A
      A --> P[Task SOP files]
      P --> R[Reference compiler and runtime]
      R --> O[Receipts and reports]

The CLI accepts independent KB and work paths. It inventories every regular input file, preserves user-owned guidance, and creates a maintained skill link. Codex is the included coding-agent adapter; a generic standard-input adapter is the extension seam for future tools.

The SOP kernel parses positional circuits, compiles immutable wire graphs, rejects invalid dependencies, and executes relevant slices with structured outcomes. Mandatory semantic matching, closure, persistent caches, and production isolation remain later milestones.

Specifications and historical material

The current DS specification matrix is authoritative for implemented behavior. DS001 defines coding style, source layout, file-size guidance, and test organization.

The repository also retains the first Romanian design package in sop_lang_circuits_design_specs_v1. It is immutable historical input: its broader roadmap informs later work but does not enlarge the current implementation contract.
