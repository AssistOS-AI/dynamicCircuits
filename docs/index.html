Documentation / Overview

Executable analysis workspaces for coding agents

Dynamic Circuits prepares either a knowledge-learning directory or a current task directory, then asks an external coding agent to interpret documents and author SOP Lang. The deterministic kernel keeps execution inspectable and independent from direct LLM APIs.

Implemented system

flowchart LR
      U[CLI invocation] --> X{workdir supplied?}
      X -->|no| KWL[KB learning workspace]
      X -->|yes| W[Task analysis workspace]
      W --> M[Input manifest]
      W --> S[Circuit skills link]
      K[Trusted KB circuits] --> A[Coding-agent process]
      KWL --> C[Reviewable KB candidates]
      M --> A
      S --> A
      A --> P[Task SOP files]
      P --> R[Reference compiler and runtime]
      R --> O[Receipts and reports]

With only -kbdir ./kb, the CLI learns candidate circuits from the KB's own input/. Adding -workdir ./work/task-001 selects the default analysis flow. It inventories every regular input file, preserves user-owned guidance, and creates maintained skill links. Codex is included; a registry and generic standard-input adapter form the extension seam for future coding agents.

The runtime skill catalog consists of analyze-task, author-sop-circuit, and circuit-learner. These project-owned skills govern complete input coverage, circuit authoring, and reviewable KB learning.

The SOP kernel parses positional circuits, compiles immutable wire graphs, rejects invalid dependencies, and executes relevant slices with structured outcomes. Mandatory semantic matching, closure, persistent caches, and production isolation remain later milestones.

Specifications and historical material

The current DS specification matrix is authoritative. The design guide, assurance model, provenance and scale guide, and lifecycle and roadmap make the complete theory navigable while labeling implemented and planned layers.

The first design package in sop_lang_circuits_design_specs_v1 remains byte-for-byte historical. The coverage index maps every original DS, schema, checklist, decision, template, and agent role into maintained documentation.
